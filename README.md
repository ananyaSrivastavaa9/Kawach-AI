## 🧠 **How It Works**

"Ye rubbish hai" → 65/100 🚨 Toxic  
Triggers: rubbish → Rewrite: "Ye kaisa content hai?"

**Thresholds:** 🟢0-24 **Safe** | 🟡25-54 **Moderate** | 🔴55-100 **Toxic**
